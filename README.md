# «Чистая Империя» — сайт-визитка (демоверсия)

Это **неофициальный дизайн-концепт** для клининговой компании «Чистая Империя» (Казань). Проект предназначен для демонстрации потенциальному покупателю и не принимает заявки.

## Содержимое

- Статический сайт на HTML, CSS и JavaScript без сторонних зависимостей.
- Восемь оригинальных SVG-файлов: главное интерьерное изображение, шесть иллюстраций услуг и логотип-концепт.
- Дополнительно 27 SVG-иконок внутри HTML.
- Анимация первого экрана, появление разделов при прокрутке, переходы и эффекты наведения, `prefers-reduced-motion`.
- Шесть направлений: квартиры, дома, после ремонта, генеральная, поддерживающая уборка и мойка окон.
- Интерактивное сравнение видов уборки.
- Конфигуратор: вид работ, объект, площадь, дополнительные пожелания, комментарий; текст запроса копируется в буфер, но **никуда не отправляется**.
- Контакты из открытых каталогов, FAQ, мобильное меню.
- Минимум обводок и рамок, вся графика — SVG.

## Запуск локально

Можно открыть `index.html` в браузере. Для надёжного локального запуска:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000/ в браузере.

## Размещение на Vercel

1. Распакуйте ZIP и загрузите **содержимое папки**, включая `index.html`, в новый репозиторий GitHub, например `chistaya-imperiya-website`.
2. В Vercel создайте Project и импортируйте этот репозиторий.
3. Framework Preset: **Other**. Не нужно устанавливать зависимости или запускать сборку. Укажите Output Directory: `.` при необходимости.
4. Желаемое имя проекта: `chistaya-imperiya-demo` (доступность домена не проверялась).
5. Проверьте проект после развёртывания.

Рекомендуемый Git-коммит: `feat: launch Chistaya Imperiya demo website`.

## Настройка

Главные параметры находятся в `config.js`: телефон, адрес, перечень услуг, доступность, варианты уборки и пожелания. Дополнительные тексты находятся в `index.html`. Перед переделкой в официальный сайт следует синхронизировать контакты также в HTML (включая футер) и подключить согласованный рабочий способ приёма заказов.

## Обязательные действия перед официальной публикацией

- Согласовать название, телефон, адрес и возможность посещения офиса.
- Подтвердить реальные услуги, состав работ и тарифы. В демо **нет выдуманных цен**.
- Получить права на фотографии работ и логотип компании. Все текущие изображения — иллюстрации, не фото заказов.
- Определить способ приёма заявок и требования к обработке персональных данных.
- Снять пометку о демонстрации и запрет индексации (`robots.txt`, meta robots, `vercel.json`) только после согласия владельца.
- Разместить действующие юридические документы при необходимости.

## Достоверность сведений

Источники: [Яндекс Услуги](https://yandex.ru/services/kazan_uborka-kvartiry) и [отраслевой каталог](https://laundry-wash.ru/clean/kazan/chistaya-imperiya-221382999214). Уборка квартир, домов и после ремонта упоминается в прямом предложении Яндекса. Генеральная и поддерживающая уборка и мойка окон встречаются в стороннем каталоге и **требуют отдельного подтверждения**. Опубликованная площадкой цена «500 ₽» не имеет достоверной единицы расчёта, поэтому не используется.

В проекте нет вымышленных сотрудников, наград, сертификатов, гарантий, отзывов или точных цен. Фотографии реальных работ не используются.
